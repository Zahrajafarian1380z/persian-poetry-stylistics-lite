# 📜 سامانه سبک‌شناختی اشعار فارسی (نسخه سبک و سبک‌وزن / Lite Edition)

این مخزن شامل **نسخه سبک، سریع و قابل‌حمل (Lightweight & Portable)** از سامانه تحلیل سبک‌شناختی و استخراج مفاهیم کلیدی اشعار فارسی است. 

این نسخه بهینه‌سازی شده تا بدون نیاز به سخت‌افزارهای سنگین یا کارت گرافیک (GPU)، با حداقل مصرف حافظه (کمتر از ۱۰۰ مگابایت رم) روی تمامی سرورهای رایگان، وب‌سایت‌های شخصی، سایت‌های وردپرسی و محیط‌های محلی به صورت آنی اجرا شود.

---

## ⚡ تفاوت این نسخه با نسخه کامل (ParsBERT)

برای راحتی کاربران و پژوهشگران، این پروژه در دو لایه طراحی شده است:

| ویژگی | ⚡ نسخه دمو و سبک (این مخزن) | 🚀 نسخه هوشمند و پیشرفته (ParsBERT) |
| :--- | :--- | :--- |
| **هدف** | اجرا روی وب، سایت‌های وردپرسی و سرورهای رایگان | تحلیل دقیق پژوهشی و مقالات علمی |
| **مکانیسم تحلیلی** | TF-IDF + گراف هم‌آیی (Co-occurrence) + شباهت سیاقی | مدل ترنسفورمری **ParsBERT** + تحلیل گراف چندلایه |
| **مصرف رم (RAM)** | بسیار ناچیز (کمتر از ۱۰۰ مگابایت) | سنگین (نیاز به بیش از ۱ گیگابایت رم و GPU) |
| **سرعت پردازش** | آنی (کمتر از ۱ ثانیه) | چند ثانیه |
| **محل اجرا** | Render / WordPress / Local / Portable | Google Colab |

## 🛠️ ویژگی‌های فنی نسخه سبک (Lite)

* **پردازش متون ادبی:** نرمال‌سازی حروف فارسی، حذف متوازن استاپ‌وردها و حفظ کلمات کلیدی سبک‌شناختی.
* **تحلیل چندلایه گرافی:** استخراج شبکه هم‌آیی واژگان (Word Co-occurrence) و شباهت سیاقی بر پایه TF-IDF.
* **رتبه‌بندی ترکیبی (Multi-Rank):** ترکیب الگوریتم PageRank با TF-IDF و اعمال وزن‌های اختصاصی برای سبک‌های **خراسانی، عراقی، هندی و معاصر**.
* **رابط کاربری تعاملی (Gradio):** امکان تعیین تعداد کلمات کلیدی خروجی، رسم گراف بصری شبکه‌ای و ارائه جدول امتیازات.
